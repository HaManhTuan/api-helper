# Table: payout_batches

## Overview
- **Purpose:** Batch header for helper settlement cycles.
- **Module:** admin-payouts-and-settlement.
- **Record Volume:** Medium.

| Column | Type | Nullable | Default | Description | Logic name |

| period_end | DATE | NO | - | Cycle end date | Period end |
| status | VARCHAR(30) | NO | 'pending_approval' | pending_approval/approved/paid/failed | Status |
